# HarmonyOS frontend

Native ArkTS / ArkUI shell for Sujiu.

HarmonyOS owns ArkUI navigation, text input, window/safe-area behavior, animations, credential storage and platform file/share capabilities. Character/world-book/prompt behavior stays in Rust.

The source skeleton targets the current project direction (API 26 class devices). DevEco/Hvigor-generated project metadata and signing configuration are intentionally not fabricated here; signing keys/config remain local and the Rust bridge is wired as a separate integration milestone.
